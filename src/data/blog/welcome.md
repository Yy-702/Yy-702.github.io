## 欢迎来到我的博客

niihao12lsdad3
大家好！欢迎来到我的个人博客。这是我使用 Astro 和 AstroPaper 主题搭建的第一个博客网站。

### 关于这个博客

这个博客主要用于：

- **技术文章** - 分享编程学习心得、技术教程和项目经验
- **生活随笔** - 记录生活中的点滴思考和感悟
- **项目展示** - 展示我参与或开发的个人项目

### 技术栈

本博客使用以下技术构建：

- **Astro** - 现代化的静态站点生成器
- **AstroPaper** - 简洁优雅的博客主题
- **Tailwind CSS** - 实用优先的 CSS 框架
- **Pagefind** - 静态站点搜索功能

### 功能特性

- 📝 支持 Markdown 和 MDX 格式
- 🏷️ 标签分类系统
- 🔍 全文搜索功能
- 💬 评论系统（Giscus）
- 🌙 深色/浅色模式切换
- 📱 响应式设计，支持移动端
- ⚡ 静态生成，极速加载

### 后续计划

我计划在博客中分享以下内容：

1. 前端开发技术（React、Vue、Astro 等）
2. 后端开发经验（Node.js、Python 等）
3. 个人项目开发日志
4. 读书笔记和思考感悟

感谢你的访问！如果你有任何问题或建议，欢迎通过评论与我交流。
